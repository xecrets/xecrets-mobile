# Google Play store listing assets

These are tools and assets for the Play store listing.

## App icon

[`icon/xecrets-ez-play-store-icon-512.png`](icon/xecrets-ez-play-store-icon-512.png)

Generated by [`../tools/New-PlayStoreIcon.ps1`](../tools/New-PlayStoreIcon.ps1) from the
same two SVGs the app icon itself is built from,
`src/Xecrets.Mobile/Resources/AppIcon/appicon.svg` (background) and `appiconfg.svg`
(foreground). To regenerate it after any change to those files, run:

```pwsh
pwsh store/tools/New-PlayStoreIcon.ps1
```

It meets the [Play icon design specifications][spec]: 512x512 px, 32-bit PNG,
sRGB, 1024 KB limit, full square with no pre-applied rounded corners, no drop
shadow, and fully opaque. Play applies rounded corners etc when it renders the
listing.

It is deliberately identical to the launcher icon.

[spec]: https://developer.android.com/distribute/google-play/resources/icon-design-specifications

## Feature graphic

[`feature-graphic/xecrets-ez-feature-graphic.png`](feature-graphic/xecrets-ez-feature-graphic.png)

Generated by
[`../tools/New-PlayStoreFeatureGraphic.ps1`](../tools/New-PlayStoreFeatureGraphic.ps1),
which composites the listing icon above, and the `01-main-actions.png` phone
screenshot below (its Play-mandated padding is cropped back off first to recover
the original 1080x2400 capture). The only new content is the brand colour, read
from `appicon.svg`, and the title/tagline text — set in Roboto, Android's system
font (bundled under [`../tools/fonts/roboto`](../tools/fonts/roboto), Apache
License 2.0). Regenerate after changing the icon, the main-actions screenshot,
the tagline or the app name:

```pwsh
pwsh store/tools/New-PlayStoreFeatureGraphic.ps1
```

Meets the [Play feature graphic spec][assets]: 1024x500 px, 24-bit PNG, no alpha, under 15 MB.

## Phone screenshots

[`screenshots/phone`](screenshots/phone) — A number of PNGs, numbered in upload order.

Sourced from raw Pixel 7a captures (1080x2400) taken while walking through the
app: register a local profile, encrypt/decrypt/share from the main menu, browse
an encrypted file sitting next to its originals in the device's own Documents
folder, view a decrypted file, share an encrypted copy through the Android share
sheet, and dark mode etc. The raw captures are 1080x2400 (9:20), taller than
Play's screenshot rules allow. Play store wants exactly 16:9 landscape or 9:16
portrait. Each was padded to 1350x2400 (exactly 9:16) with solid-color bars
sampled from the screenshot's own top-left pixel — no cropping.

To refresh from a new set of raw captures: pick the ones to keep, rename each to its
`NN-description.png` slot, then run
[`../tools/Add-ScreenshotPadding.ps1`](../tools/Add-ScreenshotPadding.ps1), e.g.:

```pwsh
pwsh store/tools/Add-ScreenshotPadding.ps1 -InputPath path\to\renamed-captures
```

It pads whatever it's given and writes the result into `screenshots/phone` under the
same filenames, leaving already-compliant images untouched.

| File | Shows |
| --- | --- |
| `01-main-actions.png` | Main menu — Decrypt, Encrypt, Encrypt copy to share |
| `02-create-profile.png` | Registering a local profile: an identifier plus a master password that never leaves the device |
| `03-files-in-place.png` | Encrypted file sitting next to its originals in Documents |
| `04-view-decrypted.png` | Viewing a decrypted document instantly |
| `05-share-anywhere.png` | Sharing an encrypted copy via the Android share sheet |
| `06-dark-mode.png` | Main menu in dark mode |
