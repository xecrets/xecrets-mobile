# Google Play store listing assets

Uploaded in the Play Console under *Grow users → Store presence → Main store listing*.

## App icon

[`icon/xecrets-ez-play-store-icon-512.png`](icon/xecrets-ez-play-store-icon-512.png)

Generated by [`../tools/New-PlayStoreIcon.ps1`](../tools/New-PlayStoreIcon.ps1) from the
same two SVGs the app icon itself is built from,
`src/Xecrets.Mobile/Resources/AppIcon/appicon.svg` (background) and `appiconfg.svg`
(foreground). Regenerate it from the repository root after any change to those files:

```pwsh
pwsh store/tools/New-PlayStoreIcon.ps1
```

It meets the [Play icon design specifications][spec]: 512x512 px, 32-bit PNG, sRGB,
well under the 1024 KB limit, full square with no pre-applied rounded corners, no drop
shadow, and fully opaque. Play applies the rounded corners (30% of the icon size) and
the drop shadow itself when it renders the listing, so baking either into the asset
would double up.

This has to be a separate file because the build produces nothing that fits. `MauiIcon`
generates launcher icons only: for Android that is the `mipmap-*` densities, the largest
of which is 192 px at xxxhdpi, plus the adaptive icon XML. Play takes the listing icon
as an upload, not from the app bundle.

Note that the artwork is deliberately identical to the launcher icon rather than a
separate store design, so the listing and the installed app show the same mark.

[spec]: https://developer.android.com/distribute/google-play/resources/icon-design-specifications

## Remaining listing assets

Not yet produced. Requirements as of this writing, see the [Play Console help][assets]
for the authoritative list:

| Asset | Requirement | Folder |
| --- | --- | --- |
| Feature graphic | 1024x500 px, PNG or JPEG, no alpha. Required. | `feature-graphic` |
| Phone screenshots | 2 to 8, 16:9 or 9:16, 320 to 3840 px on the shorter side. Required. | `screenshots/phone` |
| 7-inch tablet screenshots | Up to 8, same format rules | `screenshots/tablet-7-inch` |
| 10-inch tablet screenshots | Up to 8, same format rules | `screenshots/tablet-10-inch` |

[assets]: https://support.google.com/googleplay/android-developer/answer/9866151
